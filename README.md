# MissRose Pro

Full-featured Telegram group manager + Music + AI chatbot.

## Features
- Bans, kicks, mutes, warns, promotes, pins
- Filters, notes, blacklists, locks
- Welcome/goodbye, captcha, antispam, antiflood
- Federation bans, night mode, disable commands
- YouTube music streaming in voice chat (`/play`)
- AI chatbot (OpenAI / Groq)
